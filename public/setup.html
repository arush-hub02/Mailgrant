Self-Hosting & Deployment Guide

Deploy Your Own Mailgrant Proxy

Deploy a private zero-trust email proxy in ~5 minutes on Cloudflare Workers and Cloudflare D1 (100% Free Tier eligible). Follow this step-by-step walkthrough with interactive command generators.

Node.js 20+ LTS Free Cloudflare Account Free Google Cloud Account Zero Domain Required (uses workers.dev)
STEP 01

Clone the Repository & Install Dependencies

Clone Mailgrant from GitHub and install project dependencies using npm.

bash / powershell 
# 1. Clone the Mailgrant repository
git clone https://github.com/arush-hub02/Mailgrant.git
cd Mailgrant

# 2. Install dependencies
npm install

# 3. Run security regression tests (32 automated tests)
npm test
Automated Test Suite: Running npm test exercises the embedded SQLite engine, cross-workspace security boundaries, AES-256-GCM encryption, and token extraction regex before you touch any cloud resources.
STEP 02

Connect Cloudflare & Provision D1 Database

Sign into your Cloudflare account from Wrangler, provision a free serverless D1 SQLite database, and apply migrations.

wrangler cli 
# 1. Log into your Cloudflare account (opens browser)
npx wrangler login

# 2. Create the D1 SQLite database
npx wrangler d1 create mailgrant

# Notice: It outputs your database_id, e.g. "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
# Ensure your database_id in wrangler.jsonc matches this ID!

# 3. Apply the database migrations to remote D1
npx wrangler d1 migrations apply mailgrant --remote
What this creates in Cloudflare D1
1
16 Database Tables: Tables for isolated workspaces, mailbox bindings, whitelisting rules, access keys, encrypted message projections, and audit ledgers.
2
Zero Full Email Bodies: D1 only stores extracted 6-digit OTP codes or single-use links, encrypted at rest with your private CONTENT_KEY.
STEP 03

Create Google Cloud OAuth Credentials

Configure Google OAuth 2.0 so you can connect your Gmail account via official read-only Google APIs.

Google OAuth Redirect URI Calculator

Type your Cloudflare Worker domain or custom domain below to compute your exact Google Redirect URI:

Authorized Origin: https://mailgrant.arushdeepguptacse.workers.dev
Authorized Redirect URI: https://mailgrant.arushdeepguptacse.workers.dev/auth/google/callback
Google Cloud Console Step-by-Step Instructions
1
Open Google Cloud Console: Visit console.cloud.google.com and create a new project named Mailgrant Proxy.
2
Enable Gmail API: In the search bar, search for Gmail API and click Enable.
3
Configure OAuth Consent Screen: Go to APIs & Services → OAuth consent screen.
- Select External user type.
- App name: Mailgrant.
- Scopes: Add openid, email, profile, and https://www.googleapis.com/auth/gmail.readonly.
- Test Users: Add your personal Gmail address (e.g. you@gmail.com).
4
Create OAuth 2.0 Client ID: Go to Credentials → Create Credentials → OAuth client ID.
- Application type: Web application.
- Name: Mailgrant Web Client.
- Authorized JavaScript origins: paste your Worker origin (from helper above).
- Authorized redirect URIs: paste your Redirect URI (from helper above).
- Click Create and copy your Client ID and Client Secret.
STEP 04

Configure Cloudflare Worker Secrets

Store your Google credentials and cryptographic encryption key safely as encrypted secrets in Cloudflare Workers.

Cryptographic CONTENT_KEY Generator (AES-256)

Generated locally in your browser using crypto.getRandomValues(32). Never stored or sent over the network:

configure secrets 
# Run each command in terminal and paste value when prompted:

# 1. Put Google Client ID
npx wrangler secret put GOOGLE_CLIENT_ID

# 2. Put Google Client Secret
npx wrangler secret put GOOGLE_CLIENT_SECRET

# 3. Put your generated AES-256 Content Key
npx wrangler secret put CONTENT_KEY

# 4. Put your exact Worker HTTPS origin (no trailing slash)
npx wrangler secret put APP_ORIGIN

STEP 06

Automate Deployments with GitHub Actions

Set up automatic deployments so every git push origin master tests and redeploys to Cloudflare with zero manual commands.

GitHub Repository Secrets Configuration
1
Open GitHub Repo Settings: Go to your GitHub repository → Settings → Secrets and variables → Actions → Click New repository secret.
2
Add Secret 1: CLOUDFLARE_API_TOKEN: Go to Cloudflare API Tokens → Create Token → Use the Edit Cloudflare Workers template → Copy token value and paste into GitHub Secret.
3
Add Secret 2: CLOUDFLARE_ACCOUNT_ID: Find your 32-character Account ID on the Cloudflare Dashboard overview (right sidebar) or run npx wrangler whoami in your terminal.
That's it! Once configured, every push to master will automatically run your 32 security regression tests, compile the showcase, and deploy directly to Cloudflare!
